# Restaurant App 🍴

Este é um aplicativo React Native para exibição de restaurantes, categorias de pratos, pedidos e checkout. Ele utiliza o Expo para testes e desenvolvimento.

## ⚙️ Funcionalidades

- Mapa com restaurantes.
- Exibição de categorias e produtos.
- Checkout com notificações locais.
- Alternância de tema (claro/escuro).
